====================================================================
                          neovim-config
====================================================================
ABOUT
  This repository holds my configuration for NeoVim 0.12+,
  my primary* text editor on every system I use.

DEPENDENCIES
  - rg (ripgrep),
  - Python 3,
  - tree-sitter-cli,
  - git,
  These can all be installed with your package manager. I use
  mason.nvim for language servers, formatters and other language-related
  tools.

INSTALL
  Simply clone the repository into your neovim config
  directory, after installing the necessary tools, and run
  neovim.

CREDITS
  A good portion of the code comes from Rosh404's own dotfiles:
  https://github.com/Rosh404/dotfiles
  This was the reason I aggressively stripped my configuration
  down to just a couple files.
